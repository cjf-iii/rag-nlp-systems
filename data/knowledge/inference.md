# Inference and capacity

Inference is the process of using a trained model to produce an output. Latency measures the response time for one request. Throughput measures how many requests the system can complete during a fixed interval.

Batching can raise throughput by processing several inputs together, but larger batches consume more memory and can increase the time an individual request waits. Capacity planning balances latency targets, expected traffic, memory, and utilization.
